00 How to read

Default agent harnesses stop at the session boundary. They can reason and invoke tools while a session is open, but future presence, authenticated delivery, durable state, privacy-scoped context, and post-session recovery need explicit infrastructure.

Each entry names the missing capability, the narrow interface that supplies it, and the concrete command or protocol an agent can use.

01Sundial

A command-agnostic scheduler that lets an agent create reliable work for its future self.

Why the harness falls short
Most built-in schedulers are cron-like: useful for fixed clock times, but too rigid for real-life events such as sunrise, a changing condition, or a one-off moment with readiness gates.
Interface contract
Sundial persists cron, solar, poll, and one-time triggers, runs any shell command, and keeps execution state portable across daemon restarts.
Design choices
  • Daemon wired to a macOS LaunchAgent plist, wrapped in caffeinate -i to hold a sleep assertion and keep firing through system sleep
  • A crash or reboot triggers launchd's KeepAlive; the daemon replays the same reconcile-then-catch-up sequence either way, so no fire is silently lost
  • Desired state lives in a git data repo — a push that fails from lost network still lands locally and retries at the next reconciliation point
  • A daemon-wide active-hours window defers any fire outside human waking hours to the next opening, rather than dropping it or calling at 3am

02Outreach

A utility interface for calls, messages, email, Discord, and per-channel history.

Why the harness falls short
A model can draft words, but drafting is not authenticated delivery. Calls, messages, email, and channel history each need a real recipient, transport, and verifiable result.
Interface contract
Outreach exposes channel-specific commands with explicit recipients and objectives. Workflow policy decides whether, when, and why to contact someone.
Design choices
  • Bridges Twilio Media Streams straight to Gemini Live instead of a scripted STT→LLM→TTS pipeline — cuts round-trip latency to ~0.5–1.0s per turn against 1.5–3s for the scripted approach
  • Gemini runs the live turn as an autonomous subagent from a system prompt, objective, and persona — not the calling agent itself
  • outreach call steer lets the main agent inject a drift-tolerant nudge or a forced near-verbatim say line without taking the call over outright
  • Twilio's answering-machine detection reports whether a human or machine picked up
  • Gemini's own send_dtmf/end_call tool calls let it navigate an IVR menu and hang up cleanly on its own

03Notion Gateway

A schema-aware bridge between a human Notion workspace and agent-readable commands.

Why the harness falls short
A context window is temporary, and Notion’s visual workspace is shaped for humans. Agents need stable IDs, live schemas, bounded writes, and compact receipts.
Interface contract
Notion Gateway discovers approved databases, validates live schemas before writes, supports dry runs, and fails closed on unknown destinations or properties.
Design choices
  • Trusts exactly one registry — the Gateway page in Notion, read by ntn-gateway show as the sole source of approved databases, so an agent never rediscovers workspace structure or guesses scope
  • Every write validates against the live schema first; an unknown property, invalid status, or not-yet-live select value comes back with the valid options listed inline, so the next command can self-correct without a human in the loop
  • Responses stay token-efficient by default — compact JSON, normalized summaries instead of full API echoes
  • aggregate pages fans out across every approved database in one command, grouping by live status and capping/sorting by recency instead of a query per database

04Whoami

A privacy-aware router that reveals only the category of personal context needed for the task.

Why the harness falls short
Generic memory either withholds needed context or exposes an undifferentiated biography. Personal facts need purpose-aware routing before they enter a task.
Interface contract
Whoami routes a request to the smallest relevant category—identity, contact, home, family, or life history. Knowing a fact never becomes permission to act on it.

05Headless Recovery

A failure protocol that preserves retry state, attempts bounded repair, and makes any unresolved problem visible.

Why the harness falls short
When no one is watching, an exception can disappear with the process. The next session may not know what failed, what changed, or whether retrying is safe.
Interface contract
The protocol preserves retry state, records sanitized evidence, posts a concise status, and dispatches one guarded investigation that can repair or escalate.
Cross-cutting protocol

06Interfaces become a system only inside a workflow.

Consider a scheduled follow-up: Sundial wakes the command, Notion Gateway loads the canonical task state, and Outreach delivers the result. The workflow decides what counts as complete and whether silence, a digest, or an interruption is appropriate.

Now consider the same run failing after the session closes: the recovery protocol preserves the retry, records evidence, and attempts one bounded investigation. No single CLI owns either experience; the workflow supplies the purpose, order, policy, and stopping condition.

The parts supply handles. Composition supplies the human outcome.
