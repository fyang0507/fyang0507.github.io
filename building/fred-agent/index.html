fred-agent · an operating environment for general-purpose agents

A Life With Handles

The capability already exists. The opportunity does not.

active system · 2025—now last revised · July 2026 source · private working repository
Why couldn't I welcome an agent to participate in my life? The question behind Fred Agent
00The gap

Remarkable intelligence, stranded behind a screen.

Today's agents can solve problems that feel impossibly difficult. Ask the same intelligence to operate seamlessly in a person's life, and it becomes strangely helpless.

The intelligence is ready. Everyday life has not made room for it. Fred Agent is my attempt to make that room.

01What changes

Give the intelligence somewhere to act.

Not continuous presence or universal autonomy—just the right opening at the right moment.

time

The agent can arrive without being summoned

It can wake by clock, sunlight, condition, or one future moment. I do not have to become the scheduler myself.

reach

The agent can leave the chatbox

It can call, message, observe, update shared state, or ask for a decision when waiting would make the result worse.

shared knowledge

The agent and I share one knowledge base

I read and edit it through a familiar workspace. The agent reaches it through its own interface. Neither side has to work like the other.

recovery

Execution failure starts recovery

It preserves retry state, records evidence, and attempts a bounded repair before escalating what still needs a human.

02The system

Enablement, in one line.

Small handles become useful only when a protocol composes them around a human outcome.

01 Atomic handles

Scheduling, communication, memory, perception, and personal context.

02 Workflow protocols

Rules for composition, constraints, retries, and human handoff.

03 Real-life outcomes

A call made, a thought preserved, a bin noticed, a draft finished, a failure closed.

04Still growing

The environment is the durable part.

Components will change. Workflows will be deleted. The runtime will change again. The enablement environment is what lets the next agent continue.

Not a better chatbot. A life with handles.
