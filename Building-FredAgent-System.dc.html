01 / outcomesWhat becomes possible

The capability was there. The opportunity was missing.

Enablement means opening four practical doors into real life.

Presence

Arrive when the obligation exists

Wake by clock, sunlight, condition, or one future moment.

Reach

Enter the interfaces life still uses

Call, message, email, observe, and preserve a result.

Continuity

Carry work across sessions

Share one Notion workspace with the human for co-authoring, while canonical task state lets any new agent or session resume without relying on model memory.

Recovery

Recover after execution failure

Preserve the retry, attempt a bounded fix, and tell the human only when action is still needed.

03 / operationsBefore it runs alone

Every unattended workflow must answer four operational questions.

The handles explain what a workflow can do. These decisions define when it acts, what survives, when it interrupts, and how anyone can reconstruct the result.

01 · Time

Name the trigger, active window, timeout, and condition for staying asleep.

02 · State

Name the canonical record, checkpoint, and exact point at which work is complete.

03 · Attention

Separate silent recovery, written digest, and the rare decision worth an interruption.

04 · Evidence

Keep enough receipts to prove the side effect, retry safely, and explain cleanup.

04 / boundaryWhat it is not

A growing environment, not a universal autonomous agent.

Fred Agent is not a foundation model, a personality around one provider, or a catalog of API wrappers. It is not proof that every personal workflow should be automated.

It makes selected parts of life legible and actionable to a general-purpose agent.
